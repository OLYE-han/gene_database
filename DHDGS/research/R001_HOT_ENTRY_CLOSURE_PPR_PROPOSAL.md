# R001-A15：热点入口闭包＋局部PageRank＋边界优化提案

2026-10-28实施更新：完整热点闭包、局部PPR完整扩张与复验已实现，详见[正文状态](R001_SUBGRAPH_SELECTION_AND_EXECUTION_PLAN.md#hot-entry-closure-ppr)和[实验报告](../test/hot_entry_community_20261028/REPORT.md)。结构正确性通过不等于净吞吐或质量保持达标；以下保留原评审内容。

日期：2026-10-28（Asia/Shanghai）。状态：用户设想的可行性评审与算法细化，非实验，未修改运行代码或默认配置。关联[完整局部区域方案v0.2](R001_SUBGRAPH_SELECTION_AND_EXECUTION_PLAN.md)、[Research](../Research.md#r001-a15)。本提案增加候选方法，不替代既有完整层次区域/单种子h跳对照。

## 1. 判断与三者分工

可实现，但应拆成“拓扑完整核心、候选排序、受约束边界选择”三步：

- 完整有向h跳邻域保证相对于声明图的内部层记录完整。
- 热点触发闭包将通过h跳可达关系连接的热门入口组成一个候选核心。
- 局部个性化PageRank（PPR）发现核心外围联系较强的候选；它不是直接复制清单。
- 电导率/有向出口率用于比较候选边界，最终仍受完整性、字节、净卸载、准备时间和质量约束。低电导率不是独立的唯一算法，也不自动证明ANN驻留。

该组合保证的是图邻域完整，不是凸几何区域无孔洞；若仍要求“同几何域内所有点都在”，需叠加几何范围全量枚举，成本另计。增加顶点只可能把原出口变为内部边，不新增或改写原始图边，也不保证平均度、归一化密度或实际回源率单调改善。

## 2. 热点与图的定义

冻结源A的索引epoch、top-K热点集合H及热度窗口。第一轮建议同时保存请求频率与`请求率×平均源CPU`两种热度，后者作主排序；重复请求发生次数不能因query ID去重而消失。热点统计稳定性、入选/退出滞回和窗口时长作独立变量。

源内图H_A取A拥有完整记录的顶点和这些顶点之间的原始有向边；原始跨机边仍记录为出口。禁止把跨机边从完整图删去后宣称全局h跳保证。全局版本需收集多节点原始邻接、全局去重和合同/epoch一致性，第一阶段不实施。

## 3. 热点触发闭包

### 3.1 数学定义

```text
B_h(s) = {v : directed_distance_HA(s,v) <= h}
S_0 = {最热门的待覆盖入口}
R_t = union[B_h(s), s in S_t]
S_(t+1) = S_t union (H intersect R_t)
停止：S_(t+1) == S_t，且所有已触发种子的完整h跳邻域均已完成。
```

等价地，在K个入口上构造概念关系`s→t iff t in B_h(s)`，求初始入口的有向可达闭包；不必显式预先构建全部K×K关系。已触发入口只激活一次，因此无资源限制时最多激活K次，算法会终止。但一个长热点链可使区域覆盖大半源片；终止不代表容量可接受。

发现新热点不取消旧种子的剩余扩张。热点在某个种子的最外层被发现时，也必须从它重新获得h跳扩展额度。不能用一个全局visited布尔量阻止已见顶点在新种子下继续传播。

实现可用队列中的`(vertex, remaining_hops)`和`best_remaining[vertex]`：只有剩余额度更大时才再次扫描/传播，邻接记录可缓存。每次发现热点先执行一次性激活，再处理传播；h=0时闭包仅为种子。最终以多源最短距离复验所有距S不超过h的成员，记录来源/最小层数与边界。

### 3.2 资源截止不能伪装完整闭包

完整记录、全部邻居编码、目录和峰值空间都计预算，另设最大扫描边数、最大种子数和计划CPU/墙钟上限。所有阈值到达都记录截断原因。

若严格闭包超额，第一版拒绝该候选，再试更小h或其他种子；不返回半层、不忽略已遇到热点后仍称严格闭包。已完成的单种子球可以保留为明确标注的退化候选（不是热点闭包），只在单独对照中使用。无法完成枚举的候选不能发布。

一次性闭包可能很大，建议先测h=1/2、K=16/64/256的机会曲线；不是预先认定h=2适用。对seq_2M也必须报告实际出度、节点/边增长和完整字节，而不是用最大出度幂当实测值。

## 4. 多入口PPR与完整块扩张

### 4.1 PPR输入与截断

核心种子集合S作个性化重启分布，权重可为热度的幂并设置单入口权重上限，避免最大入口吞掉所有质量。其他合法入口仍保留。冻结原图边，第一轮用均匀出边概率，访问加权边作为后续独立消融，未采样边不能被赋零并删除。

```text
p = alpha * restart_distribution + (1-alpha) * P_transpose * p
```

alpha是重启概率，不是沿边继续概率。先扫alpha=0.15/0.30两个候选；收敛残差、扫描边数、内存和运行时间同时有上限。

在核心加有界外围探索图上做稀疏push或幂迭代。对每个已载入顶点，分母保留原始完整出度/出边权重；指向未载入点或其他服务器的概率质量进入显式OUT状态，不能只按剩余内部边重新归一化。OUT在沿边步骤自环、重启时回S；无出边顶点使用明确的自环约定并另报死端，不把它当高质量可搜索社区。

这是包含边界泄漏的局部近似模型，不是完整全局PPR；未展开质量、OUT质量和残差必须报告。必要时增加探索壳层做稳定性对照；未知外部回流不得当作零代价。局部图准备、原图读取和邻接缓存计入计划成本。

### 4.2 不直接复制PPR排名前M个点

PPR输出只用于排列外围候选锚点，可比较p(v)及出度归一化分数；有向图中的排序为启发式，不套用无向PPR sweep定理。

每个候选锚点v对应一个完整B_h(v)扩张包；或使用已有完整单元目录，但需标清该策略的保证。第一轮为保持同一h跳语义，仅使用完整球。候选锚点必须与当前区域有原始有向可达联系，优先从当前出口目标生成；PPR探索到的更深点须同时纳入完整连接路径所涉及的包，不能生成无法从入口到达的孤岛。

加入包后若遇到新热点，推荐重新执行第3节热点闭包，达到固定点才成为可评价候选。该闭包仍计入此次增量成本；任一预算超限，整个新增候选回滚。扩张是单调增加成员，锁定核心R0，不能用sweep截掉核心或某个完整球的内部顶点。

最终区域可表示为一组完整h球的并集（含所有被触发热点）。任一点只要对某个种子的距离小于h，其在H_A中的出邻居都在区域内。这个保证允许不规则、多叶瓣形状，并不等于没有几何孔洞。

## 5. 低电导率评价与停止

标准无向加权电导率为`cut(R,V-R)/min(vol(R),vol(V-R))`。若用对称化图必须明确边权和全图体积来源；只在局部已加载子图内忽略所有外边会人为得到好分数。构建完整对称化/入边统计需要额外成本，不能视为免费。

第一版直接在原有向图记录：

```text
eta_out(R) = 所有从R到外部的原始边权 / R的全部原始出边权
eta_query(R) = 样本中指向外部的相关动作权重 / 全部相关动作权重
```

eta_out称“有向出口率代理”，不冒充标准无向电导率或全局Markov链电导率。出边权重为零时结果记未定义；eta_query分别记录发现、批准与实际跨机动作。第一轮原边等权，查询权重仅作独立指标，避免以缺失样本隐藏出口。

每加入一个完整扩张包/闭包，就重新枚举真实出口、完整字节、Tready和U_safe。保留多目标候选前沿，最后以质量和容量合格条件下的预计净卸载收益选择；结构出口率只作辅助。不能仅为降低eta无限吞并冷点，也不能要求每一步eta严格下降而错过组合收益。若新增顶点产生更多新出口，可以拒绝该包。

不需要修改原图边。实际搜索仍由扩展函数批准出口扩张；PPR、后台建图和读取事件不得发派查询分支。

## 6. 多子图、方向性与重叠

一个区域候选完成后，从尚未被有效覆盖的热门入口中选择下一个。区分“记录被复制”“作为触发种子闭包完成”“可路由服务入口”：只有实际通过入口/质量评估，才计有效服务覆盖；未通过项记录原因，不假定所有K入口都必须覆盖。

有向闭包不是无向连通分量：a可达b不代表b可达a。按热度先后处理会影响区域组合，固定seed/平局规则，报告顺序敏感性。各入口都须核验在该区域的可用搜索能力，不能把a的效果外推到b。

后续区域的完整邻域若遇到已有区域记录，不能把这些记录从新区域中删掉，否则破坏完整性。候选生成允许重叠；规划阶段按增量服务覆盖/真实额外空间决定保留、合并或放弃。合并后重新进行闭包、容量、入口及质量核验。第一版不实现跨版本物理共享记录，所有重复字节照实收费。

同一入口对应多个候选时，先选择一个主服务副本，分流概率总和不超过1；源/目标余量共同约束。没有被服务的入口继续使用原图。第一轮只部署一个最优区域，其余候选离线审计，再验证多区域联合控制，避免同时引入区域选择和副本调度两种变化。

## 7. 风险与针对性验证

| 风险 | 对照/检查 |
|---|---|
| 热点链使闭包覆盖大半分片 | h/K/完整字节曲线；热点串联构造图；严格闭包超额拒绝 |
| 全局visited错误截断新种子扩张 | 菱形交汇图、热点位于边界、环、同点不同剩余深度；与逐种子完整BFS并集比对 |
| PPR把区域剪成零散点 | 每个最终种子h球成员复验、内部缺点注入必须拒绝 |
| 局部PPR忽略外边而虚假封闭 | OUT质量与探索范围消融；完整出度校验；外连边很多的小图 |
| 电导率降低但搜索变差 | 同包/同预算真实查询驻留、回源、源/总CPU及Recall，而非只看结构分数 |
| 多入口合并后部分入口质量下降 | 按入口/查询群配对召回，入口少样本标未定 |
| 多区域重叠重复计算收益 | 显式请求分配与字节账本；不删除重叠成员；固定区域组合对照 |
| 选图太慢，热点已消失 | 采样/扫描/PPR/闭包/提取/发布全阶段成本及过期计划审计 |

消融顺序：单种子完整h球 → 热点闭包 → 热点闭包加PPR候选但按净收益排序 → 再加入有向出口率辅助选择。额外对照完整层次区域、现工作集合；初期固定E0和相同复制发布版本，之后用固定副本验证E1/E2。相同额外RAM/SSD上限并报告实际字节曲线，不删点凑等大小。共用既有0.95召回及配对质量约束，至少三次交错重复；每入口/热点群样本不足则不能宣布该群质量保持。

## 8. 实现可行性与配置候选

现有candidate为入口工作集合评分，本算法需新增完整BFS闭包与PPR planner，不是改一个阈值。原始索引已有邻接可读，副本打包、合同校验、RDMA传输、版本发布可复用。优先在释放GIL、有界原生后台规划器中实现；不能让Python逐点访问阻塞负载续期。

扩展参数附在[设计YAML](R001_SUBGRAPH_SELECTION_DRAFT.yaml)的hot_entry_community_candidate中，仍为非运行schema，不更改默认region.strategy。上线前需冻结索引/单元版本、计划来源、停止原因和完整成员/边界摘要。先小图正确性及固定索引机会分析，再独立实机实验。机制可实现，但收益尚无实验依据，不能据此关闭R001。
