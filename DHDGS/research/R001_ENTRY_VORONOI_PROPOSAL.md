## 1. 用户构想及可行性判断

以热门路由入口为种子，扩展到向量更接近其他竞争入口的地方，以几何归属替代固定最大图深度 h。这可表述为以路由样本为站点的 Voronoi 分区；它比图跳数更直接描述一个入口的潜在查询服务范围，但不能据路由入口推断所有真实近邻都在同一区域，也不能用遇到第一个越界点就停止的 BFS 证明几何成员完整。

代码核对：`cpp/native.cpp::Router` 使用原始 float32 L2 的 HNSW 搜索；`cpp/runtime_bindings.hpp::route` 以返回结果第一项为根入口，其余为备用入口。RaBitQ 估距随后用于种子状态，不将 HNSW 变成精确最近入口证明。现有索引 manifest 为 2,000,000 点、2560 维、20,003 个路由样本。平均一个精确最近入口单元约 100 个原始点只是全局算术平均，不能代表热门单元大小；重复坐标、入口所属节点及容量分布需实测。只比较热门入口会遗漏真实竞争者，夸大热门区域。

## 2. 几何定义与推断边界

P 是全部冻结路由入口，A 是源节点记录全集，e_i 是入口；d 为欧氏距离，非平方 L2。平局由固定 ID 规则处理，重复坐标入口先按确定性规则归组。

```text
C_i = {x in A : i = argmin[j in P] (||x-e_j||^2, entry_id_j)}
```

若 query q 的精确最近入口是 e_i，不能推出其最近数据点 x 仍在 C_i。例如一维入口 0、2，q=0.99，最近数据点 x=1.01；路由选择 0，但 x 归入口 2。目标点与 query 非常接近，也仍可能越过分界。

对不同坐标入口，定义 query 到各分割超平面的最小有符号距离：

```text
m_i(q) = min[j != i] (||q-e_j||^2 - ||q-e_i||^2) / (2*||e_j-e_i||)
r_k(q) = query 到真实第 k 近邻的欧氏距离
```

精确最近入口且 `m_i(q) > r_k(q)` 时，所有 top-k 位于该入口的几何单元内。这是空间归属的充分条件，不是有限预算图搜索的召回保证；限制到源 A 后还需单列其他源独有的目标点。线上不知道真实 r_k，历史/校验只用于估计其分布，不能把估计当保证。

一个更易计算但偏保守的充分条件是：精确最近与第二近入口的非平方距离差大于 `2*r_k(q)`。这些式子不能直接套用代码中的平方距离差，也不能将 HNSW 的第二返回项默认当全体入口的精确第二近。

## 3. 推荐的完整区域

### 3.1 相邻入口组与柔性边界

G 是一组空间相邻、需求相关且容量允许的服务入口。冷入口仍参与竞争，只是未必获得副本。

```text
d_G(x)   = min[i in G] ||x-e_i||
d_out(x) = min[j in P\G] ||x-e_j||
gap_G(x) = d_G(x) - d_out(x)
R_tau    = {x in A : gap_G(x) <= tau}, tau >= 0
```

G 非空且为 P 的真子集。tau=0 对应组内最近入口区域的并集（边界平局按固定规则；允许复制平局边界须明确），tau 增大时纳入边界缓冲。tau 以欧氏距离为单位；也可用冻结入口尺度归一化后配置无量纲参数，但不同组尺度与极近入口应加下限并实测。

若 q 经精确路由进入 G、`||q-x|| <= r`，则 `gap_G(x) <= 2*r`。若实际入口相对全体最近入口有非平方距离劣差 delta，则上界放宽为 `delta+2*r`。这给缓冲校准提供解释；没有已知 r/delta 上界时仍是经验规则。tau 过大可吞并全片，不能代替容量限制。

组只在明确的几何邻近、真实边联系、需求和容量条件下合并。遇到另一个热门入口不自动无限连锁合并；无关局域保留独立副本。以字节及净卸载评分选择多个组，不能仅为降低出口率吞并冷单元。

### 3.2 成员枚举与图连通是不同问题

图沿一条分支遇到不满足条件的点，只能停止那条分支，不能结束其他方向。更严重的是，原图可能存在 `入口 -> 域外桥点 -> 域内目标`，拒绝域外桥点会漏掉属于几何区域的目标。几何域凸也不能保证采样的有向原图在该域内连通；源内记录限制还会增加此风险。

完整性实现有两条路径：

- 冻结几何谓词后扫描源的全部记录，分块判断归属，建立成员列表；或预先建设带版本的全量归属目录/倒排成员表。近似最近入口分类产生的是近似目录，不能宣称精确 Voronoi 完整性。
- 将图遍历用于发现和排序，并用全量目录独立补齐所有应包含成员。只用入口 BFS 得到的集合须明确称受限可达分量，不称完整几何单元。

对最终成员读取完整原始邻接，保留内部边、外部出口与邻居估距码；独立核验实际开放入口集合的有向可达性。若缺少通路，选择完整邻接单元/几何层作为缓冲通道，或增加经验证可用的入口；重新核算容量及逐入口搜索质量。超限时拒绝该候选或重新定义更小的完整区域，不能删除域内冷点补齐容量。多源可达仍不代表任意入口可达所有点。

图边界定义为 `B_graph={u in R : exists (u,v) in E, v not in R}`。几何内部点也可能因长边成为图边界；本算法不保证出口只在几何分界附近，也不继承完整 h 球的“源内出口仅位于最外层”性质。其他数据节点独有记录的边仍是显式出口，不默认为已复制。

### 3.3 PPR 与低电导率的分工

几何谓词确定核心与可扩充范围；PPR 仅在真实图上提出扩充方向，最终按完整单元/完整几何层增加成员。禁止直接保留 PageRank 最高的若干单点而再次产生域内缺点。

在局部计算中保留原始完整出度和指向 OUT 的概率质量，不能丢掉外边再归一化，让候选看似封闭。标准无向电导率 `cut(R,V\R)/min(vol(R),vol(V\R))` 可在声明的对称化辅助图上用于社区提议；上线判据仍报告有向出口率、真实首次派发、源/目标 CPU 和召回。不把有向出口比例命名为标准电导率，不套用无向 PPR 理论保证 ANN 搜索。

完整单元的并集保证单元内成员齐全，不自动保证整体为凸集或无几何孔洞。第一版保护完整核心，只增添连通缓冲；若要求单个严格几何域，则应扩充其整体谓词阈值并枚举全部新层，不能任意拼接 PPR 单元。

## 4. 开销与加速边界

设检查 V_c 个候选点、扫描 E_c 条边、每点检查 K 个竞争入口、维度 D。局部候选判断计算约为 `O(V_c*K*D)`，图遍历约 `O(V_c+E_c)`；精确比较全部 M 个路由入口时 K=M。通过竞争者固定向量差可将平方距离差写成点积，消除重复计算范数，但不消除 K*D 的主要代价。预计算、批量矩阵运算、SIMD 和跨区域复用均可研究。

以 V_c=100,000、K=32、D=2560 为算术示例：320 万次距离评估、约 81.92 亿个坐标项；若每个候选原始向量读一次，float32 向量逻辑量约 1.024 GB，另加邻接、输出包和代码依赖。20,003 个路由向量约 204.83 MB，可常驻内存。逻辑读量不等于物理 SSD 读量；缓存、读取顺序和页面重叠决定实际成本。这些是工作量计算，不是实测耗时。

当前 h 球规划器的 `adj()` 主要读取邻接，新增几何判断需要原始向量或编码，可能比纯邻接扫描更慢。现有 A21 的约 136 秒离线规划/验证不能推导本算法会更快；减少盲目图扩张与增加高维判别之间需实测。

在当前全量 2M 数据上，朴素全部入口分类约为 400 亿次向量距离、1.024e14 个坐标项，须分块取最小值，不能物化所有点对距离矩阵。源内一轮只按该源实际记录量计。全量目录可在静态索引上摊销，但初建、版本更新、目录 RAM/SSD、软边界的次近入口及间隔信息都要计费；只保存 top1 归属不足以支持任意 tau。

百亿规模仅扫描一次 2560 维 float32 原始向量就约 102.4 TB，不能每个热点都全量扫描。需要随索引分布式预建/维护的分层目录或可剪枝几何块，且保持完整性证据。

优化候选及边界：

1. 对入口建立辅助近邻索引，按候选 x 自适应发现竞争入口；入口 e_i 最近的固定 16/32/64 个入口不必包含它所有 Voronoi 邻居，高维尤其不能默认足够。
2. HNSW 或 RaBitQ 先筛选、边界点精算；精算筛选集不证明未漏掉竞争者。严格标签需完整竞争集合或有确定性包围界的检索；概率误差界只能按其实际适用条件报告。
3. 若预先限定 `||x-e_i|| <= R`，所有可能击败 e_i 的竞争入口均在离 e_i 不超过 2R 的范围内，可用完整范围枚举给出严格竞争者裁剪。这额外引入几何半径，虽不是图深度 h，也需独立校准；近似 kNN 列表不能替代完整范围枚举。
4. 按物理行排序合并向量/邻接读取、以 epoch 绑定缓存；一次读取复用于多个相邻入口组。规划在有界后台原生任务执行，限制对前台 CPU、SSD 和缓存的干扰。
5. 候选邻接装载后 PPR 每轮成本约 O(E_c)，排序约 O(V_c log V_c)；重复全量重算不同区域仍昂贵，应按已读取图和完整单元维护增量边界账本。

全局仍约束同源活动/排空/构建预约副本物理字节合计 `<= alpha*B_source`，加单包、行数、RAM、时间和边扫描上限。它们是资源护栏，不是停止到半个区域后声称完成。原子核心超限时分组、显式几何细分或拒绝；不能直接删除成员。

## 5. 对 DHDGS 的收益预期及限制

优势是把入口服务范围和区域形状直接关联，避免固定 h 在不同密度处截得过小或过大；缓冲可覆盖查询近邻跨越入口分界的情况，多入口并集吸收高频内部跨界，PPR/边界优化保留导航联系。以上是待检验假设。

A21 自然流副本接流约 1.8%，源内真近邻包含率约 48%。前者受已注册入口集合和路由条件限制；只扩大现有入口的成员不自动提高接流率。若合并/新增入口，须将它们明确注册为副本可服务入口，并逐入口校验，而非假设扩大图就自动获流。

后者可能由新几何区域改善，但硬 Voronoi 单元也可能更小、更碎；原图短路径可能走到其他单元。当前副本首次外派大多由概率抽样触发，预算比例 .75 会使剩余预算较早交给源。因此图更完整不自动推迟回源或提高源净卸载。选图阶段不能替代扩展函数批准查询派发，实验需固定派发和预算后再做独立消融。

## 6. 预登记验证顺序（部分离线执行，结果见第7节）

先做静态假设检验，再决定是否完整实现：在互斥历史/校验/测试集合上，历史只定义热点和参数，校验选择后冻结，测试结果不能反向调区。没有真实时序，只使用明确标注的受控漂移。

| 检查 | 判定用途 |
|---|---|
| HNSW 实际根入口与全入口精确最近入口的匹配、距离劣差 | 判断路由是否足以支撑几何归属推断 |
| 同入口严格单元/不同 tau/相邻入口组包含真实 top10 的比例 | 直接验证目标归属假设及质量—容量曲线 |
| m_i(q)/r_10(q) 分布、跨界真实近邻的距离 | 判断缓冲所需尺度，避免凭感觉设 tau |
| 完整目录成员与受限 BFS 成员差、原图可达性及域外导航工作 | 识别内部遗漏和通道成本 |
| 入口/组大小、物理包及编码依赖、不同入口接流、每入口样本量 | 防止总体均值掩盖局部质量和容量问题 |
| 规划距离次数、扫描边数、向量逻辑/物理读、缓存峰值、全部发布耗时 | 计入新算法的真实维护成本 |

之后比较：现有完整 h 球 → 单入口严格单元 → 多入口加缓冲 → 再加 PPR/完整单元边界优化。固定 alpha、执行参数与同一数据；既报告实际容量曲线，也做同召回约 95% 的配对 QPS、每命中源 CPU、源进程占核、目标/总 CPU、跨机次数和 p99。预建验证通过后再测在线构建干扰。不能因为电导率降低就宣布图质量或卸载收益提高。

## 7. R001-A22快速实验结果与修订方向

`entry_voronoi_pilot_20261029`，2026-10-29，离线诊断完成；研究问题保持开放。564个校验query、2041个独立评估query，全部20,003入口竞争，对两个四入口组扫描源0全部907,512记录。评估根入口精确匹配98.29%，严格区域源内top10包含率仅24.55%/22.89%；缓冲系数0.15后83.16%/82.84%。所以根入口接近正确不足以支持“遇到几何分界就结束”的强假设；多入口缓冲保留研究价值。

第一组0.15加入口保护为37,622点、估算包516.74MiB，静态包含率83.16%，而同入口h3为44,777点、655.33MiB、60.85%。但前者成员原图可达率仅86.83%，后者100%；前者已包含评估真近邻中1.37%的出现次数从实际入口不可达。包估算小21.15%尚未计完整桥接，不能写成最终容量收益。仅一跳保护不足以补齐导航；低电导率不替代该必要条件。

修正重试的两组完整核心枚举536.47s、约102.47亿次入口距离检查；PPR排序后8个完整单元验证未完成。连同一次RSS失败，构建累计1199.49s触及1200s上限。第二组仅核心成员完成，拓扑和PPR未形成结论。修正重试峰值12.62GiB，物理读记账0，属于缓存条件而非冷SSD测试；初版数值平局反例和16GiB失败均保留。

校验对应组仅7/11条，均低于64条门槛；冻结后的评估202/321条不能反过来解除门槛。因此没有真实检索/源CPU/QPS结果，未修改生产或DESIGN。完整160K评估路由目录里两组仅覆盖0.33125%的根流量；扩大成员不自动扩大入口覆盖。完整[报告与图表](../test/entry_voronoi_pilot_20261029/REPORT.md)、[审计](../test/entry_voronoi_pilot_20261029/audit.json)、[TestLog](../TestLog.md)保留全部结果。
